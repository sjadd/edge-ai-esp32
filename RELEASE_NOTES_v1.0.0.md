# Release Notes - v1.0.0

## Summary

Initial public release of SmartFarm Edge AI for ESP32.

## Included in this release

- Modular embedded decision engine for irrigation scoring
- Smart farm controller abstraction
- Simulated sensor input workflow
- Relay-based irrigation actuation logic
- Arduino example sketch
- Professional GitHub documentation
- Public repository-ready structure

## Intended audience

This release is intended for developers, researchers, and engineers working on smart farming, agricultural automation, and ESP32-based IoT solutions.

- MQTT and Wi-Fi integration
